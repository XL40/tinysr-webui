# 设计与排查记录

本文记录拼接伪影问题从归因到修复的完整过程与实测数据，供想理解或复现各设计决策的人参考。正文 README 只保留使用说明。实验工具与对照图未随仓库分发。

**口径**：1950² 夜景 → 7800²（或 1920² 亮图 → 7680²），超分结果 BOX 缩回原图尺寸逐像素比；「台阶」= 112px 网格相邻 cell 残差均值差（中位 / p90，/255 尺度），平滑区与暗部（L<60）分层统计。

## 1. 拼接一致性：为什么有 DC 对齐和 tonefix

transformer 对整块 64×64 latent 做全局自注意力，每个 tile 拿到的"全局语境"不同，
输出的平均亮度会随 tile 内容漂移；单步蒸馏模型还对暗部有系统性提亮。两者叠加
在平滑/暗部区域表现为肉眼可见的"图块感"。以 bicubic 参考为锚的实测：

| 指标 | 无修正 | 有 DC 对齐 + tonefix |
| --- | --- | --- |
| 平滑区相邻 tile 亮度台阶（中位 / p90） | 0.48 / 1.53 | 0.23 / 1.12 /255 |
| 暗部（L<60）相邻 tile 台阶（中位 / p90） | 0.48 / 1.34 | 0.32 / 1.07 /255 |
| 低频 tone 的 tile 边界富余 | ×1.24 | ×1.03（= 无台阶） |
| 暗部层（L20–40，占 41% 像素）平均偏移 | +1.29 | −0.41 /255 |

注：融合窗（overlap）实测 8→16 反而更差（统计核心区变小），默认 8 即最优。

## 2. 经典后处理对照：OCM / Multiband（均不采纳）

| 方案 | 平滑区台阶 | 暗部台阶 | 曝光 L20–40 | PSNR |
| --- | --- | --- | --- | --- |
| dcfix + tonefix（默认） | **0.21 / 0.95** | **0.30 / 0.99** | **−0.33** | **33.68** |
| + OCM（限幅增益） | 0.80 / 2.65 | 0.78 / 2.14 | −0.43 | 29.51 |
| 仅 OCM（无 dcfix） | 0.81 / 2.63 | 0.76 / 2.13 | −0.42 | 29.53 |
| OCM + Multiband | 0.81 / 2.65 | 0.77 / 2.14 | −0.43 | 29.49 |
| 仅 Multiband | 0.21 / 0.94 | 0.30 / 0.99 | −0.33 | 33.68（=无差异） |

结论：有 bicubic 参考这个**绝对锚**时，链式邻居锚定（OCM）只会引入额外扰动；
多频带融合解决的低频台阶已被 dcfix 消除。残余的 ~0.3/255 是纹理级差异，
这两类后处理都不针对它。

## 3. 逐 Tile 光度校准（参考引导回归）——实测不采纳

另一条路线：在融合后的整图上，以整张 bicubic 参考为绝对锚，逐 tile（512px 窗口
核心 448²）在 σ=32 低频上做 Huber 稳健回归 `R_low ≈ gain·S_low + offset`
（gain 限幅 ±10%、平坦区仅估 offset、色度只做加性限幅校正），参数场平滑后
双线性插值成连续场再应用（低频残差 `S + α·(T(S_low)−S_low)` 保护高频）。

| 方案 | 平滑区台阶 | 暗部台阶 | 曝光 L0–20 / L20–40 | PSNR |
| --- | --- | --- | --- | --- |
| dcfix + tonefix（默认，A） | **0.23 / 0.98** | **0.32 / 1.09** | +7.9 / **−0.41** | **33.68** |
| 裸融合（无任何修正） | 0.48 / 1.53 | 0.48 / 1.34 | +11.7 / +1.29 | 34.97 |
| B 逐 tile 亮度回归 | 0.71 / 2.46 | 0.70 / 1.84 | +14.5 / +1.52 | 33.41 |
| C = B + Lab 色度 | 0.72 / 2.49 | 0.72 / 1.86 | +14.5 / +1.44 | 33.34 |
| D = C + 参数场平滑 | 0.73 / 2.48 | 0.71 / 1.84 | +14.4 / +1.47 | 33.67 |
| E = D + 低频残差应用 | 0.75 / 2.47 | 0.70 / 2.05 | +12.1 / +1.26 | 33.56 |

失败原因（残差图可直接看到）：94% 的 tile 回归 gain 触 ±10% 限幅——模型输出在
平坦区的低频对比度天然大于 bicubic 参考，回归想压缩对比度（斜率 0.1–0.4），
限幅后实际效果是全局 ~−10% 对比度压缩（中亮部 −1~−2/255）；σ=32 低频中位数
估计混入纹理能量，相邻 tile 估计值分歧处经参数场插值产生新的低频斑块
（远山变暗、人物/前景过冲），等效于另一种"接缝"。信息量上，decode 时逐 tile
DC 统计（dcfix）严格优于事后低频回归估计，该路线无改善空间，停止实验。

## 4. 伪影的内容依赖性与两类"物理修补"尝试（均无增益）

伪影是**内容依赖**的（模型行为，与推理栈无关——OpenVINO NPU 版同图台阶 0.50 ≈
ncnn 0.48，只是裸输出整体偏暗、末尾还做了全局 AdaIN，观感上更干净）：

| 图 | 裸输出台阶 平滑/暗部 | dcfix+tonefix 台阶 平滑/暗部 |
| --- | --- | --- |
| 夜景（meanL=65，大片平坦暗天空） | 0.48 / 0.48 | 0.23 / 0.32 |
| 亮图（meanL=108） | 0.40 / **0.18** | 0.16 / **0.09** |

平坦暗部的 tile 漂移最大、且人眼对暗部亮度差最敏感——这就是"有的图几乎看不到、
暗图极其明显"的原因。两类修补尝试（1950² 夜景）：

| 方案 | 平滑区台阶 | 暗部台阶 | 结论 |
| --- | --- | --- | --- |
| 基线 dcfix+tonefix | 0.23 / 0.98 | 0.32 / 1.09 | — |
| 半步相位二次推理取平均（裸输出） | 0.39 / 1.25 | 0.40 / 1.15 | 裸输出 −19%，聊胜于无 |
| 半步相位二次推理取平均（基线上） | 0.23 / 1.02 | 0.31 / 1.12 | 无增益，2× 耗时 |
| 窗函数 余弦坡 / Hann（默认=余弦坡） | 0.23 / 0.98–0.99 | 0.32 / 1.09–1.10 | 三者无差异 |

结论：dcfix 之后残余的 ~0.3/255 是各 tile **纹理统计差异**（注意力对平坦暗部
内容的上下文不同），既不在融合过渡带里（窗函数无效），也不是相干 DC 分量
（相位平均无效）。要进一步压低只能动模型本身（微调/LoRA 约束 tile 上下文一致性），
后处理已到极限。

## 5. 精确残差回注（residfix）——采纳，默认开启

换个角度绕开"估计"：不估参数、不建场，直接传**精确残差**。
`D = BOX↓4(S)` 是输出的低频带（均值保持），`R = 原图 − D` 就只含低频伪影
（tile DC 漂移、台阶、色调偏移——它们全在周期 ≥ ~24px 的频段），而纹理细节
属于高频带。对 R 做低通（滤掉原图自带的 JPEG 8px 块噪声，×3 放大实测是
唯一可见副作用）、4× 上采样加回，输出低频带即精确对齐原图，SR 高频纹丝不动。
这正是上游 `wavelet_color_fix`（SR 高频 + 参考低频）的残差形式，但截止频率
设在 tile 尺度而非 Haar 2px，纹理保留完全不同。

| 方案 | 平滑区台阶 | 暗部台阶 | PSNR |
| --- | --- | --- | --- |
| dcfix+tonefix（原基线，夜景/亮图） | 0.23 / 0.98 | 0.32 / 1.09 | 33.68 / 40.69 |
| + 残差回注 σ=0（未低通） | 0.01 / 0.07 | 0.02 / 0.08 | 46.6 |
| + 残差回注 σ=4（**默认**） | **0.03 / 0.11** | **0.06 / 0.31** | **36.2** |
| 亮图 + 残差回注 σ=4 | **0.04 / 0.11** | **0.04 / 0.14** | 42.5 |

残差图上天空 banding、暗部过冲斑全部消失；×3 放大暗部裁块与原基线视觉等同
（无噪声注入、颗粒连续）。代价：8–24px 周期的中频色调差（~−1/255）不纠正、
CPU 上 +~2s、峰值内存 +~800MB。σ=0（不平滑）会把原图 JPEG 噪声搬进暗部
（×3 可见斑驳），σ=4 是精度/噪声最优点。

注意精度链路：整个残差链（下采样、减法、低通、上采样、加回）必须全程 fp32、
只在写 PNG 时量化一次——tile 台阶本身就是亚 1/255 量级，任何 8bit 中间量化
都会在校正前就把它丢掉（等于白算），这也是暗部渐变色彩断层的主要来源。
